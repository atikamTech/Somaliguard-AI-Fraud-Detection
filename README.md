# SomaliGuard: Real-Time Fraud Defense for EVC-Plus

## Mission
Protecting the Somali mobile money ecosystem using predictive behavioral analytics.

## Tech Stack
- Frontend: MERN Stack (Next.js/React + TailwindCSS)
- Backend API: FastAPI (Python)
- Machine Learning: Random Forest ML Model

## Core Intelligence
**Stateful Memory:** The system tracks velocity and location anomalies (Mogadishu vs Remote IP) by holding active sessions in memory, correlating high-velocity transfers and out-of-bounds geographic location shifts.

## Forensics
Automated PDF reporting for Central Bank compliance. The system packages incident timestamps, routing data, device IDs, location approximations, and risk percentages straight from the AI engine into legally formatted documents.
